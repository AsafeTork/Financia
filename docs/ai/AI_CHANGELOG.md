# AI Changelog — Financia Brand Studio

## 1.0.0 (2026-07-07)

Initial schema release.

### Modules

- `palette` — brand colors with semantic fields (style, mood, mode)
- `typography` — fonts with semantic fields (style, size)
- `sidebar` — navigation with semantic field (style)
- `header` — top bar with semantic field (style)
- `cards` — surfaces with semantic field (style)
- `buttons` — actions with semantic field (style)
- `inputs` — form fields with semantic field (style)
- `borderRadius` — rounding with semantic field (style)
- `spacing` — layout density with semantic field (density)
- `shadows` — box shadows with semantic field (intensity)
- `animations` — UI motion with semantic field (speed)
- `layout` — general layout with semantic field (sidebarPosition, density)
